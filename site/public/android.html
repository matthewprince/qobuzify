Android · first public release

Everything Qobuzify does, on Android.

It runs the Qobuz web player inside a native shell, then draws its own interface over the top. Now Playing, the queue, your library, search, settings and word-by-word lyrics, all laid out for one hand rather than a mouse. You will need your own paid Qobuz subscription: Qobuzify adds to Qobuz, it is not a way to get Qobuz for free.

Download APK 0.3.0 · 477 KB Other platforms

Two things to know first. This is a sideloaded app, not a Play Store listing, so Android will warn you and you will have to allow the install yourself. It is signed with our own key, so updates only ever come from this page.

On Android the audio is lossless FLAC but not bit-perfect. It goes through the web player and the shared Android mixer, and no setting will change that. If bit-perfect output is what you came for, you want the desktop app on Linux, or the PowerShell installer on Windows.

What is in it

Every screen redrawn

Now Playing, the queue, your library, search and settings. None of it is the desktop layout shrunk down.

Word-by-word lyrics

The same renderer as the desktop app, on the same lyrics service. It follows the audio, so it does not drift the way a line timer does.

Lockscreen and Bluetooth controls

A proper media session, so your notification, your car stereo and your headset buttons all behave.

Music that keeps playing

Screen off, another app open, phone in a pocket: a foreground service holds the stream.

Themes and extensions

All of them, switched live from settings. No restart.

Installing

  1. Download the APK

    Straight onto the phone, or copy it across from a computer.

  2. Open it and allow the install

    Android will ask whether it can install apps from this source. Allow it for whichever browser or file manager you used.

  3. Sign in with your Qobuz account

    The same account you use everywhere else, on Qobuz's own sign-in page.

  4. Say yes to the battery prompt

    It asks once to be left out of battery optimisation. Without that, Android stops your music the moment the phone goes in a pocket.

Qobuzify for Android

The Qobuz web player in a native shell, with a mobile interface built for it rather than a desktop layout squeezed onto a phone. Themes, the extension suite and word-by-word lyrics come along. It needs your own paid Qobuz subscription: Qobuzify adds to Qobuz, it is not a way to get Qobuz for free.

What you get

  • A real mobile UI. Now Playing, queue, library, search and settings, drawn for a phone.
  • Word-by-word lyrics. The same karaoke renderer as the desktop app, on the same lyrics API.
  • Lockscreen and Bluetooth controls. Native media session, notification, headset buttons.
  • Background playback. Audio keeps going with the screen off.
  • Themes and extensions. Switched live from the in-app settings panel.
Read this before installing. This is a sideloaded app, not a Play Store listing, so Android will warn you and you will have to allow it explicitly. It is signed with our own key, which means updates have to come from this page. Audio is lossless FLAC but not bit-perfect: it plays through the web player and the shared Android mixer, and no setting changes that. If bit-perfect output matters to you, that is the desktop app on Linux, or the PowerShell installer on Windows.

Installing

  1. Download the APK on the phone, or copy it across.
  2. Open it. Android will ask whether to allow installs from this source: allow it for your browser or file manager.
  3. Open Qobuzify and sign in with your Qobuz account.
  4. Say yes when it offers to exempt itself from battery optimisation. Without that, Android kills background audio.

Requirements

  • Android 8.0 or newer.
  • A paid Qobuz subscription.
  • Around 2 MB of storage, plus whatever the system WebView caches.

Verifying the download

Every release is signed with the same key. If the signing certificate ever changes, the APK did not come from us. Check it with apksigner verify --print-certs qobuzify.apk.
